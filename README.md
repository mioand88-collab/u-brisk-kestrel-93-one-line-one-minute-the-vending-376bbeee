A single pickup line, spoken by a vending machine to a passing human: its coils, its hum, its buttons and its exact change, with the turn landing in the last few words. `main.ts` writes that one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validating first that it is 1–200 characters, a single line, and not only whitespace.

## Run it

```sh
node main.ts
```
